Xlib — C 언어 X 인터페이스
한국어 풀어쓴 번역 · 예시 포함

원문: Xlib - C Language X Interface (X Consortium Standard). 낱말 하나하나 옮긴 번역이 아니라, 장·절 순서를 따라 뜻을 쉬운 한국어로 풀고 설명과 C 예시를 덧붙였다. 함수·구조체·상수 이름은 영어 그대로 두었다. 자주 쓰지 않는 부분은 요약만 했다. 정확한 인자·동작은 원문과 man 페이지를 함께 본다.

예시 빌드: cc x.c -o x -lX11 (데비안·우분투: sudo apt install libx11-dev)

장마다 페이지가 따로 있다. 각 장 위·아래의 화살표로 앞뒤 장으로 넘어간다.
