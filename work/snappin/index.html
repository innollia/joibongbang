snappin

X11에서 마우스로 드래그해 화면 일부를 찍으면, 찍은 그림이 찍은 그 자리에 테두리 없는 창으로 떠 있습니다(항상 위). Snipaste의 "핀" 기능과 비슷합니다.

snappin.py 받기

설치

sudo apt install python3-tk python3-pil python3-pil.imagetk xclip

(xclip은 복사 기능에만 필요합니다. 다른 배포판은 tkinter + Pillow만 있으면 됩니다.)

실행

python3 snappin.py

바탕화면 설정의 단축키(예: Ctrl+Shift+A)에 이 명령을 연결해 두면 편합니다.

조작

캡처 화면
드래그영역 고르기 (놓으면 바로 그 자리에 뜸)
Esc / 오른쪽 클릭취소
떠 있는 그림
드래그옮기기
휠확대 / 축소
Ctrl + 휠투명도 (창 효과가 켜진 환경에서만)
Ctrl+C클립보드에 복사
Ctrl+S~/Pictures에 PNG로 저장
1원래 크기
N새 캡처 (여러 장 띄우기)
더블클릭 / Esc닫기
오른쪽 클릭메뉴

떠 있는 그림을 모두 닫으면 프로그램이 끝납니다.

참고

  • X11 전용입니다. Wayland 세션에서는 화면을 찍지 못하거나 검게 나올 수 있습니다.
  • Pillow로 화면을 못 찍으면 maim, import(ImageMagick), scrot 중 있는 것을 대신 씁니다.
  • 모니터가 여러 개여도 전체 화면을 한 번에 덮고 고릅니다.
