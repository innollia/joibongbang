snappin

X11에서 드래그(또는 --geometry)로 화면 일부를 찍어 PNG로 저장하는 C 프로그램입니다. --pin을 주면 찍은 그림이 찍은 그 자리에 테두리 없는 창으로 떠 있습니다(항상 위). 주석과 출력은 영어입니다.

snappin.c 받기

빌드

stb_image_write.h를 snappin.c와 같은 폴더에 두고 빌드합니다.

sudo apt install build-essential libx11-dev
wget https://raw.githubusercontent.com/nothings/stb/master/stb_image_write.h
cc -O2 -o snappin snappin.c -lX11 -lm
./snappin --help

옵션

-g, --geometry WxH+X+Y드래그 대신 이 범위를 찍음 (X11 형식, -0-0처럼 음수는 오른쪽·아래 기준)
-f, --fullscreen화면 전체
-o, --output PATH저장 위치. 파일 이름, 폴더(끝이 /이거나 이미 있는 폴더), 또는 -(표준 출력). 기본은 실행한 폴더
-n, --no-save파일로 저장하지 않음 (-c나 -p와 함께)
-c, --clipboardCLIPBOARD에 image/png로 복사
-p, --pin찍은 그림을 같은 자리에 띄움 (기본은 안 띄움)
-d, --delay SECSEC초 기다렸다 찍기 (소수 가능)
-q, --quiet오류 말고는 아무것도 출력하지 않음
-h, --help / -V, --version도움말 / 버전
  • 파일 이름은 snappin-YYYYmmdd-HHMMSS.png. 같은 이름이 있으면 -2, -3…을 붙입니다.
  • 저장한 파일 경로는 표준 출력에, 다른 안내는 표준 에러에 나옵니다. 그래서 f=$(snappin)처럼 쓸 수 있습니다.
  • 종료 코드: 0 성공, 1 취소·실패, 2 옵션 잘못.

예

snappin                              # 드래그 → ./snappin-....png
snappin -p -n                        # 드래그 → 띄우기만, 파일 없음
snappin -c -n                        # 드래그 → 클립보드에만
snappin -g 800x600+100+50 -o a.png   # 정해진 범위를 a.png로
snappin -f -d 3 -o ~/Pictures/       # 3초 뒤 화면 전체
snappin -o - | convert - out.jpg     # PNG를 표준 출력으로

클립보드에서 꺼내기: xclip -o -sel clip -t image/png > image.png
클립보드에 넣은 채로 snappin이 끝나면, 다른 것을 복사하기 전까지 뒤에서 작은 프로세스가 클립보드를 들고 있습니다(xclip과 같은 방식).

참고

  • X11 전용입니다. Wayland에서는 화면을 찍지 못하거나 검게 나올 수 있습니다.
  • 24비트 트루컬러 화면에서만 동작합니다.
  • 모니터가 여러 개여도 전체 화면을 한 번에 덮고 고릅니다.
